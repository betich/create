# Examples

These are shipped strings from BKK Virtual Move and BKK Dog Society, and they show the target voice.

| Kind | Thai | English |
|---|---|---|
| Button | ยอมรับและเริ่ม | Accept and Start |
| Button | ส่งกิจกรรมวันนี้ | Submit Today's Activity |
| Button pair | ตอบเลย · ไม่ใช่ตอนนี้ | Answer Now · Not Now |
| CTA | เลือกคนที่จะสมัคร | Choose Who's Registering |
| Share CTA | ลงทะเบียนอีเวนต์นี้! | Register for This Event! |
| Heading | ใกล้จบแล้ว! ช่วยบอกเราหน่อยว่าอะไรเปลี่ยนไป | Almost done! Tell us what changed |
| Question | วันนี้เดิน หรือปั่น? | Walk or cycle? |
| Helper | ใช้ชื่อเล่นได้ ไม่ต้องใช้ชื่อจริง | A nickname is fine. It doesn't have to be your real name. |
| Status | ส่งได้แล้ววันนี้ | You can submit today |
| Empty | ยังไม่มีใครติดอันดับ มาเป็นคนแรกกันเลย | Nobody's on the board yet. Be the first. |
| Empty | ยังไม่มีกิจกรรมที่เปิดรับ | No challenge is open yet |
| Error | ชื่อนี้มีผู้ใช้แล้ว ลองชื่ออื่น | That name is taken. Try another. |
| Error | ยังส่งไม่สำเร็จ ข้อมูลและภาพยังอยู่ กดส่งเพื่อลองอีกครั้ง | Not sent yet. Your entry and photo are safe. Tap send to try again. |
| Pending | ยังไม่นับยอด — เราจะอ่านให้แล้วบอกคุณอีกที ไม่ต้องส่งซ้ำ | Not counted yet. We'll check it and get back to you. No need to send it again. |
| Success | รับกิจกรรมแล้ว! | Entry received! |
| Correction | ทีมงานแก้ให้ตรงกับภาพหน้าจอ (คุณกรอก …) | Corrected by the team to match your screenshot (you entered …) |
| Rule | นับเฉพาะการเดินและปั่นจักรยาน ไม่รวมรถโดยสาร เรือ หรือรถไฟ | Only walking and cycling count, not buses, boats or trains. |
| Lede | ขอบคุณทุกก้าวและทุกรอบล้อที่ช่วยกันขยับกรุงเทพฯ ปีนี้ | Thank you for every step and every pedal turn that moved Bangkok this year. |
| Playful | ระยะอาจไม่เยอะ แต่คอนเทนต์ถึง! | — |
